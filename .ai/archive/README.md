# `.ai/archive/` — superseded docs

Anything moved out of `plan/`, `decisions/`, `design/`, `reviews/`, or
`handoffs/` lives here. **Never delete** `.ai/` files; always move to
`archive/` and commit the move so history is preserved.

## Convention

- Keep the original filename; add a leading `YYYY-MM-DD-` if not already
  present (helps chronological sort).
- Add a one-line `_moved.md` header in the moved file pointing to its
  replacement (if any).
- Index at the bottom of this README.
