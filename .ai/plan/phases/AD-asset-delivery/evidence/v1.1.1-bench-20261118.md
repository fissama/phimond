# v1.1.1 (AD0 + AD1 + AD2) — số đo trước/sau, 2026-11-18

**Môi trường:** container Linux, Chromium headless + SwiftShader (không GPU), preset **Thấp**, devserver Go (dữ liệu trong bộ nhớ). FPS trong môi trường này (7–9) không phản ánh máy thật; chỉ so **số texture, bộ nhớ cache, số request, thời gian tải map** giữa hai bản. Chưa đo trên iPhone Safari thật (nợ N09).

**Kịch bản:** `apps/client/tests/e2e/bench.spec.ts`: đăng ký → Triệu Linh Điện → bệ đá → Bìa Rừng → Rừng Sâu → Hoàng Môn → Quảng Trường (đi liền, không đo ở rừng vì có quái), rồi lặp 4 vòng Quảng Trường → Hoàng Môn → Thương Phố → Quảng Trường; đo sau mỗi lần tới map (chờ tải xong + 1,5 s).

- Trước: v1.1.0 + chỉ thêm móc đo (AD0), chạy trên Vite dev — `bench-20261118-v1.1.0-low.json`.
- Sau: AD0 + AD1 + AD2, chạy trên **bản build** (`vite preview`) — `bench-20261118-v1.1.1-dist-low.json`.

**Vào lại game:** v1.1.0 cache ảnh 1 giờ (tên không băm) → sau 1 giờ mỗi ảnh (~250 ảnh tới Quảng Trường) phải hỏi lại server. v1.1.1: ảnh có tên băm, nginx trả `Cache-Control: public, max-age=31536000, immutable` → trình duyệt dùng thẳng cache, không gửi request; chỉ `index.html` (no-cache, chứa bảng tên) được kiểm tra lại. Số này suy từ cấu hình cache + kiểm `unhashed = 0`; chưa đo trên nginx thật (môi trường test dùng `vite preview`).

## Cái đã sửa

- **Rò texture (F4 trong kế hoạch):** mọi bản sao texture (`clone()`) dùng cho sprite có nhiều khung, nhân vật/NPC (từng dải idle/run), linh thú, nền xa không bao giờ được dispose khi rời map → giữ ảnh gốc trên GPU mãi. Nay đánh dấu `ownedClone` và giải phóng bằng `disposeTree` khi rời map. Bóng người chơi dựng lại mỗi map cũng được giải phóng.
- **Budget texture theo preset:** Thấp 64 MB / Trung bình 128 MB / Cao 192 MB (trước 96/160/256); sau khi vào map mới, đẩy texture map cũ tới ½ budget.
- **Tên băm + cache dài:** plugin build `vite-hash-public.ts`, `src/assetUrl.ts`, nginx thêm luật `immutable` cho file băm và `no-cache` cho `/`.
- `victory.wav` (2,1 MB) → `victory.ogg` (253 KB) + `victory.mp3` (233 KB). Nhạc chỉ thử file có thật trong bản build (bỏ request 404 của bài `hall`).

## Còn lại / giới hạn

- Chưa đo preset Trung bình/Cao (SwiftShader quá chậm); chưa đo iPhone Safari thật.
- Bản build giữ cả file tên gốc (để người đang chơi bản cũ không vỡ ảnh khi rollout) → image web ~156 MB thay vì ~78 MB.
- Số request ảnh **lần đầu** vào map chưa giảm (vẫn mỗi ảnh một request): v1.1.2 (atlas) xử lý.
