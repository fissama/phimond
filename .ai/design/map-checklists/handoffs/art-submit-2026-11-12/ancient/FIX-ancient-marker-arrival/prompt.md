# Ancient arrival marker — four-frame jade rune pulse

Four horizontal 128×128 frames, centered overhead jade rune ring for map arrival. Frame progression is dim, medium, bright with nearby sparkles, medium. Generated using built-in image_gen with Ancient crystal and shadow style references. Each frame was cropped to a common centered area, nearest-scaled, alpha-thresholded to binary, and quantized jointly so all frames share a 48-color palette.
