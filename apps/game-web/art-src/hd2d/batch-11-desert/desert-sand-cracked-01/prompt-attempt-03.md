# desert-sand-cracked-01

Route: built-in image_gen. Model not exposed.

Produce FOUR seamless gameplay ground tiles for Phimond desert, 2 by2 square sheet on flat #FF00FF gutters, 1536 square. Reference1 original desert CONTENT/color authority. References2 grass and3 paving approved batch01–02 define pixel cluster size and material rendering. References4–5 spirit pets only outline/value anchors, NO characters.
Each tile is a hard-corner opaque square approximately700x700 with24px magenta gutter. Each square has EXACTLY16px uniform flat edge on ALL FOUR sides including corners; identical color on opposing edges. Interior texture density evenly distributed right up to16px inset. No wider border or central island; repeating a tile must NOT create a visible square grid. NO bevel, rounded corners, light gradient, shadows, outlines or magenta inside square. Flat overhead texture.
TOP LEFT: warm pale sand #D9B26B, irregular long BROKEN diagonal wind ripples of varying lengths, small limestone, rust and cool gray pebbles spaced evenly across square. Ripple ends dissolve before16px edge, many small clusters near edge. Do not form uninterrupted long lines.
TOP RIGHT: same flat sand base #D9B26B but genuinely different short crescent/crosswind hooked ripples and scattered small angular grit. No repeated long parallel dune ridges. Each texture detail irregular and varied scale.
BOTTOM LEFT: many SMALL weathered red sandstone paving slabs, rust #A5522B, ivory mineral patches and worn cool mauve chips; narrow irregular joints. Base and ALL joints EXACT muted greige #7C745F. Outer16px exactly same greige with NO specks. Let small broken slabs approach16px inset, not a single rectangular slab island. No wood brown mortar.
BOTTOM RIGHT: dry cracked ochre earth, flat base #B88A44, many irregular small clods with dark ochre thin branching fissures, limestone grit and tiny rust chips. Texture distributed to16px inset, NO raised disk / square island.
Same artist as approved references, Octopath inspired HD2D pixel art, deliberate squared clusters2–4tones per material,33–48 colors per tile, warm upper left local facets without global illumination variation. NO noise/dither/smooth gradients/painting/3D/objects/text.
Crucial production constraint: OUTERMOST16px OF EACH TILE IS ONE EXACT FLAT BASE COLOR, identical all sides. Everything generated, including this flat edge. Keep interior detailed up to16px so no broad frame.
