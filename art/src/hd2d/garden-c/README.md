# garden-c — kit K1

Generated assets are packed and measured with local generalized tools. The packer accepts grid, cell, canvas, pivot, and safe-area arguments; garden-b's v3 tools are unchanged.

For `bubble-thirsty`, the cell safety rule permits opaque pixels only through y=59 while the anchor is requested at y=60. The visible tail tip is placed at y=59, with the pivot one pixel below it.
