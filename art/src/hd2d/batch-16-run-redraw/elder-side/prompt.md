# Elder side-run attempt 01

References: the existing `walker-elder.run.png` for identity and `player-male.run.png` for gait timing only.

Create a horizontal one-row 8-frame side-running animation for the same elderly male NPC, preserving hat, moustache, clothes, shoes, cane and proportions. Frame 1: near leg forward/far leg trailing. Frame 5: far leg forward/near leg trailing. Frames 1 and 5 must be opposite contacts, with no duplicated half cycle. Same body height, head size, baseline and cane scale throughout. Natural alternating run, grounded feet, counter-swing; pixel art, at most 48 colors, binary alpha, no checkerboard, no text or stray pixels; target 8 cells of 192×192.
