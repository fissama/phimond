# Ambient birds — static scene overlay

Create a simple flat pixel-art prop: five tiny dark umber bird silhouettes gliding in a loose diagonal flock, each only 12–20 logical pixels wide. Slightly vary wing poses. At most one muted ochre highlight per bird. No realism, feather detailing, shading, glow, shadows, halos, haze, gradients, sky, clouds, text, or frame. Transparent background, sparse composition, crisp pixels.

Generated with Codex `image_gen`; quantized to a 16-color binary-alpha palette, then reduced at an integer 1/4 scale with nearest-neighbor sampling. Intended as a static scene overlay whose placement can be moved by the ambience layer.
